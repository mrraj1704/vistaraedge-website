# Vistaraedge Private Limited: Website

Manpower, staffing and workforce management company website.

- Single-page-app style site (hash routing): Home, About, Why Us, Services, Manpower, Process, Industries, Contact
- All images are embedded in `index.html`, so no other files are needed
- Contact details (WhatsApp number, phone, email, address) are set in the `C` object near the end of `index.html`

## Deploy with GitHub Pages
1. Push `index.html` to the `main` branch
2. Repo Settings > Pages > Source: "Deploy from a branch" > `main` / root
3. Site goes live at `https://<username>.github.io/<repo-name>/`
